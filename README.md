# 基於發電量與負載預測之家庭能源管理系統 — 負載預測結果

專題「基於發電量與負載預測之家庭能源管理系統」中**負載預測子系統**的公開結果：單戶住宅不可轉移負載的未來 24 小時預測（96 步、每 15 分鐘），供家庭能源管理排程使用。
本 repo 只放結果。

**方法**：資料為 UCI 單戶用電紀錄（2006–2010，每分鐘），扣除可轉移分錶後得到不可轉移負載，重採樣為每 15 分鐘一點。未來 24 小時的 96 步各自訓練一個隨機森林（共 96 個），特徵為最近 24 小時負載、過去 7 天同時刻負載與每日統計、日曆與氣溫；以 6 折時序滾動驗證評估。
**Taiwan scenario**：資料來自法國，假日與氣溫改採台灣（台北）設定、季節對齊台灣型態，負載數值本身未更動。
